КАПРИЗНЫЙ БОГ — версия 3 (Fabric, Minecraft 26.2)
Команды: /god, /god wrath, /god debug (показывает в чате ошибки команд), /god pun <id> (проверить наказание на себе),
         /vkusno-i-tochka (запускает эвент Кларка: следующий приход — сцена 1, через 4 прихода — сцена 2).
ВАЖНО: в проекте есть папка src/main/resources/assets (текстуры и модели). Загружать на GitHub её нужно по частям:
textures, models, items — каждую отдельно (в браузере лимит 100 файлов за раз).
